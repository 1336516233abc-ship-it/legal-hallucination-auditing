## 候选入口

候选为每次请求创建独立 Agent、索引和任务状态，显式使用 NLI/CUAD 协议。它显示最终模型输入中的全部编号证据，拦截解析/grounding 错误，并明确提示尚未完成最终语义复核。只共享模型权重、串行处理请求；调用记录限制为最近一次。

同一实例下，始终询问“任一方能否提前 30 天通知终止”，合同从 30 天改为 60 天：

|模型|普通输入|改条件输入|
|---|---|---|
|Llama 3|entailment，28.50 秒|contradiction，35.37 秒|
|Mistral|entailment，格式与 grounding 通过|非法标签，停止展示并反馈错误|

两种模型都使用了当前合同。Mistral 的格式问题仍未解决；格式通过、编号有效也不等于语义正确。原始记录：[candidate_llama3.json](acceptance/candidate_llama3.json)、[candidate_real.json](acceptance/candidate_real.json)。这 4 次请求不是基准性能估计，也不能给出稳定延迟承诺。

两次候选网页启动均返回 HTTP 200；实际 Gradio API 空输入请求均正确返回缺少输入提示。普通/改条件真实模型请求通过同一 callback 测试，未另经浏览器点击重复运行。人工盲评页面已检查数据、脚本语法和全部证据区间；浏览器视觉核对当时因控制连接异常未完成。

## 模拟故障与自动化检查

[fixture.json](acceptance/fixture.json) 是原入口的固定输出/故障注入记录，不是真实模型成绩。空输入与模型异常能被处理；旧入口仍会显示不合规生成文本和越界引用。该次原入口 HTTP 冒烟因沙箱端口访问失败，不能算网页验收通过。

候选及盲评工具有 12 项检查：当前合同隔离、全调用 token 计数、非法标签和越界引用停止、模型异常和空输入反馈、空白评审指标 null、Unicode 区间与待裁决处理、重复/缺失 ID、错误引文、缺失判定、未完成断言的拒绝。合成评分只在测试内存中使用，未写入真人盲评文件。

发布副本的检查结果见 [tests.txt](acceptance/tests.txt) 与 [tests.xml](acceptance/tests.xml)。源文件中的机器专用路径已移除，调用参数改为显式传入本地模型目录。
